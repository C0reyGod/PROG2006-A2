# PROG2006 Assessment 2 - A Mid-Autumn Adventure

**Unit:** PROG2006 Designing the User Experience  
**Assessment:** Assessment 2 - Interactive 2D Story Starter  

---

## Project Overview

*A Mid-Autumn Adventure* is an interactive digital storybook built with Unity 2D designed for children aged 7–10. The story follows two mooncake characters, Doudou and Lianlian, on Mid-Autumn night as they embark on an adventure to restore a missing piece of the moon.

## Requirements

* **Unity Version**: Unity 2022.3 LTS (2022.3.62f2)
* **Target Platform**: WebGL / Android

## How to Run

1. Clone or download this repository.
2. Open **Unity Hub**.
3. Click **Add** -> **Add project from disk**.
4. Select the root folder of this project (`mid autumn`).
5. Open the project in Unity and load the main scene located in `Assets/Scenes/`.
